# Chào Thế giới

Chào mừng bạn đến với bài viết thử nghiệm tính năng dịch thuật!

Nếu bạn đang đọc dòng này, bạn đang xem phiên bản **Tiếng Việt** của tập tin markdown (`Translation-Demo.vi.md`).

Hãy thử nhấn vào nút chuyển đổi ngôn ngữ trên thanh điều hướng ở góc trên cùng bên phải (chuyển sang "EN"). Bạn sẽ thấy nội dung này lập tức chuyển về phiên bản tiếng Anh mà không cần thay đổi trang hiện tại.

## Tính năng
- Xuất dữ liệu hoàn toàn tĩnh
- Không yêu cầu JavaScript cho điều hướng SEO
- Cơ chế dự phòng (fallback) tự động khi thiếu bản dịch
